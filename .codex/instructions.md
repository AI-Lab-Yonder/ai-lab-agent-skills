# AI Lab Agent Skills

You have access to a library of development skills in the `skills/` directory. Each skill is a `SKILL.md` file with patterns, code examples, and workflows.

## Available Skills

### Beginner
- `skills/frontend-dev/` — Build React/Next.js/Tailwind apps
- `skills/fullstack-dev/` — Full-stack with frontend + backend + database
- `skills/api-builder/` — REST API design & implementation
- `skills/landing-page/` — Quick polished landing pages
- `skills/bug-fixer/` — Systematic debugging
- `skills/test-writer/` — Add tests to existing code
- `skills/docs-generator/` — Auto-generate documentation
- `skills/refactorer/` — Clean up code safely
- `skills/database-designer/` — Schema design, migrations, relationships
- `skills/auth-system/` — Authentication & authorization

### Advanced
- `skills/tdd-workflow/` — Test-driven development (Red-Green-Refactor)
- `skills/multi-agent-orchestrator/` — Coordinate multiple AI agents
- `skills/prompt-engineer/` — Craft better AI prompts
- `skills/skill-creator/` — Create new skills from patterns
- `skills/code-reviewer/` — Automated code review with security checks

## How to Use

When a task matches a skill, read the relevant `SKILL.md` and follow its patterns. Skills contain concrete code examples and step-by-step workflows — use them as your implementation guide.
